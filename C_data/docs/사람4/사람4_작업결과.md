# 사람 4 — JAMO·LEXICON 작업 결과

현재 기준 원천은 `data/samples/jamo_dataset.csv`이며, 공개 원문에서 직접 확인하고 실제
광고로 검증한 130건만 포함한다.

| 분류                                |      목표 |      현재 | 부족/초과 |
| --------------------------------- | ------: | ------: | ----: |
| 호환자모 전체 분해 (`compat_full`)        |      40 |      12 | 28 부족 |
| 단어 중간 부분 혼입 (`partial_mix`)       |      30 |      43 | 13 초과 |
| 조합자모 U+1100대 (`conjoining_u1100`) |      20 |      20 |     — |
| 자모+다른 기법 중첩 (`mixed_technique`)   |      10 |      55 | 45 초과 |
| **합계**                            | **100** | **130** |     — |

목표 수량까지만 인정한 충족량은 72/100건이다. 추가 수집 대상은 호환자모 전체 분해 28건이다.

호환자모 전체 분해는 엄격한 판정 조건을 충족하는 공개 원문 광고가 적어 목표 40건 중
12건만 확보했다. 데이터셋의 전체 규모는 실제 원문에서 추가로 검증한 부분 혼입형과
자모+다른 기법 중첩형 데이터로 보완했다. 다만 이 보완분을 호환자모 전체 분해 건수로
간주하거나 목표 부족분을 달성한 것으로 계산하지 않았으며, 전체분해 부족분 28건은 그대로
남겨 두었다.


## `jamo.yaml` 변환 기준

`data/samples/jamo.yaml`을 기존 합성 112건에서 현재 실제 관측 130건으로 교체했다.
공통 샘플 필드는 다음과 같다.

- `id`: `JM-001`부터 연속 번호
- `category`: 전부 `JAMO`
- `subtype`: CSV의 네 분류명을 그대로 사용
- `html`: 선택자 검증을 위한 `<span>` 래퍼. 내부 문자열은 원문 전사를 변경하지 않음
- `css`: 원문에서 CSS를 수집한 데이터가 아니므로 빈 문자열
- `evidence_text`: `jamo_dataset.csv`의 `source_observed_text`와 완전히 동일
- `expected_location`: 각 샘플에서 유일한 `#jm-NNN`
- `is_positive`: 실제 광고로 검증된 행이므로 `true`
- `extra_finding`: ETC 데이터가 아니므로 `null`
- `source`: 자체 생성 표기가 아니라 각 공개 원문 URL
- `notes`: 원천 CSV ID, 분해 전 단어, 실제 분해형, 관측일, 유해 범주와 검증 메모

YAML 행은 `compat_full → partial_mix → conjoining_u1100 → mixed_technique` 순서로
묶었다. YAML 안의 광고 문구나 연락 정보는 새로 만들지 않았으며, HTML의 `span` 구조만
공통 샘플 스키마를 맞추기 위해 생성했다.

`scripts/build_person4.py` 역시 구형 합성 샘플 생성기이므로 현재 `jamo.yaml` 재생성에는
사용하지 않는다.

## LEXICON 상태

다섯 분류를 각각 100개씩, 총 500개로 구축했다. AI 확장 후보와 외부 근거가 없는 항목은
남기지 않았다. 화이트리스트는 사행산업통합감독위원회의 `제6차 불법도박 실태조사 최종보고서` 원문에서 확인했다.

공개기관 자료는 KYCI 청소년 도박 자료, 사행산업통합감독위원회 실태조사,
한국도박문제예방치유원 안내서를 사용했다. 기관 문서 출현은 불법광고 판정 근거가 아니라
용어의 실제 사용을 확인하는 근거로만 사용했다. 표제어 단독 출현으로 불법 여부를 판정하지 않는다.

사용자가  전체 500개를 명시적으로 승인해 모두 `reviewed: true`다.
승인 방식은 `explicit_bulk_approval`로 기록했으며, 항목별 승인 감사기록 500개를 유지한다.
