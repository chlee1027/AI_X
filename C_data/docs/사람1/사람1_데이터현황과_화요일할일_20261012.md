## 2. 할 일 1 - 출처 찾기와 분류 (완료)

### 2.1 무엇을 셌나

- **출처**는 샘플을 잘라 낸 웹페이지의 호스트다. `https://www.ganghwa.go.kr/health/...` 에서 잘랐으면 출처는 `ganghwa.go.kr` 이다. `www.`·`m.` 만 다른 주소는 같은 출처로 셌다. 1,549건 모두 출처 주소가 있다.
- **업자**는 광고 문구 안의 연락 핸들이나 도메인으로 묶었다. 예를 들어 `텔레@UPCOIN24` 는 업자 `upcoin` 이다. 숫자와 끝자리 도메인은 떼고 묶었다. 그래서 `12.cia565.com` 과 `34.cia158.net` 은 둘 다 업자 `cia` 다(같은 의약품 광고 틀로 도메인 번호만 바꿔 올리는 업자였다). 핸들·도메인이 없는 문구는 업자를 알 수 없다. 업자를 알 수 있는 샘플은 ETC 28.3%, 조합 28.8% 다.

## 4. 할 일 1 - 쏠림이 있을 때 중요도를 어떻게 판단할까 (아이디어)

목적이 둘이라 판단도 둘로 나눈다. **학습**에서는 한 업자가 탐지기를 덮지 않게 하고, **평가**에서는 점수가 한 업자의 점수가 되지 않게 한다.

### 4.1 학습: 묶음 역빈도 가중치

- 샘플마다 가중치를 1 / √(그 묶음의 샘플 수) 로 준다. 묶음은 업자를 알면 업자, 모르면 사이트로 한다.
- 예: annaprez 38건은 각각 1/√38 = 0.162 다. 묶음 전체의 무게가 38 에서 6.2 로 준다. 혼자 나온 샘플 1건은 1.0 그대로다.
- 1/n 이 아니라 1/√n 인 이유: 1/n 이면 annaprez 38건 전체가 혼자 나온 샘플 1건과 같은 무게가 된다. 그러면 큰 업자 안의 수법 변형(38건 안에도 수법 조합이 여러 가지다)이 묻힌다.

### 4.2 평가: 묶음 단위 점수와 재표본

- 묶음(사이트·업자)마다 F1 을 내고 그 평균을 함께 보고한다(묶음 매크로 평균).
- 묶음마다 최대 3개만 뽑아 점수를 내는 일을 200번 되풀이해 평균과 범위를 낸다. 한 묶음이 전체 점수를 끌어올리는지 드러난다.
- 업자 하나를 통째로 빼고 학습해 그 업자로 평가하는 검증(leave-one-campaign-out)을 덧붙인다. 적격평가 사이트에는 우리가 본 적 없는 업자가 나온다.

### 4.3 대회 주제에 맞춘 가중: 공공 출처 점수를 따로

- 공공 도메인 출처의 positive 와, 공공 사이트 틀(전자정부 표준 프레임워크 · 그누보드 공공 게시판) 안의 positive 를 평가에서 따로 센다.
- positive 출처의 공공 비율이 ETC 14.5%, 조합 9.7% 라, 전체 점수만 보면 「민간 쇼핑몰 게시판에서만 잘 맞는 탐지기」를 걸러 내지 못한다.

### 4.4 수법 단위 중요도: 흔한 수법과 드문 수법을 둘 다 본다

- 실제로 흔한 수법(출현 빈도)과 놓치면 손해가 큰 드문 수법은 중요도의 방향이 반대다.
- 점수를 둘 낸다. 샘플 수 그대로 낸 점수(실제 웹 분포 반영)와 하위 유형별 평균 점수(드문 수법 반영)다.
- 예: 제로폭 문자 안에서 U+00AD 와 나머지(U+200B 등)를 따로 센다. U+00AD 만 처리하는 탐지기를 가려낸다.

### 4.5 추천

학습에는 4.1, 평가에는 4.2 의 묶음 매크로 평균과 4.3 의 공공 출처 별도 점수를 함께 쓴다. 셋을 같이 보면 「한 업자 덕에 오른 점수」와 「공공 틀에서만 떨어지는 점수」를 함께 확인할 수 있다.

### 5.2 원칙: AI 가 문구를 지어내지 않는다

1. **광고 문구는 실측에서만 가져온다.** 실측 positive 와 실측 어휘 사전에서 뽑는다. 스크립트는 구조(어디에 어떻게 숨기나)만 바꾼다.
2. **페이지 틀도 실측에서 가져온다.** DECOY 를 모으며 받은 사이트 167곳 가운데 공공 도메인 106곳의 실제 HTML·CSS 에 끼워 넣는다.
3. **생성물은 표시하고 실측과 섞지 않는다.** `source_type: generated` 를 달고 학습 몫에만 넣는다. 실측 점수와 생성 점수는 따로 낸다.
4. **공격자가 실제로 넣을 수 있는 수법만 positive 로 둔다.** 「있을 수 없는 수법」에 탐지기가 맞춰지지 않게 한다.

### 5.3 아이디어 1: 공공 사이트에 광고가 들어가는 경로별로 만든다

| 경로 | 실제 예 | 쓸 수 있는 수법 | 생성할 것 |
|---|---|---|---|
| (가) 게시판 글쓰기 | 강화군 보건소 댓글, 기업 Q&A 게시판 | 에디터가 허용하는 태그·`style` 속성 안에서만. 인라인 색·크기, 제로폭 문자, 인코딩된 링크 | 숨김 + 난독화 조합, 링크 클로킹 |
| (나) 관리자 계정·웹셸로 템플릿 변조 | 대학 도메인 도어웨이 페이지(10-03 실측 4건) | head 변조, 외부 CSS 파일 변조, 푸터 링크 삽입 | 메타 클로킹, css_content, 링크 클로킹 |
| (다) 만료·하위 도메인 탈취 | 넘어간 도메인 7곳의 엔티티 인코딩 카지노 글 | 페이지 전체 | 엔티티·Base64 인코딩 |

- (가) 생성물은 실제 그누보드 · XE · 카페24 에디터의 HTML 정화 규칙(허용 태그·속성 목록)에 통과시켜 게시 가능한 것만 남긴다. `<style>` 태그는 글쓰기로 못 넣으니 css_content 는 (가)에서 만들지 않는다.
- css_content 는 (나)로만 만든다. 공공 사이트의 실제 CSS 파일 끝에 `.board_list .subject::after { content: "…" }` 처럼 규칙 한 줄이 덧붙은 형태다. 사이트가 이미 쓰는 클래스 이름에 붙여야 실제 변조처럼 보인다.

### 5.4 아이디어 2: 한 문구에서 수법만 바꾼 짝을 만든다

- 실측 positive 하나에서 문구는 그대로 두고 수법 하나만 바꾼다.
  - 숨김: `opacity:0` → 글자색 알파 0 → `-webkit-text-fill-color` → 배경과 같은 색
  - 인코딩: 숫자 엔티티 ↔ Base64 ↔ 퍼센트
  - 제로폭 문자: U+00AD → U+200B / U+200C / U+2060 / U+FEFF
- 같은 문구로 수법별 탐지 성능을 비교할 수 있고, 소프트 하이픈 76.3% 쏠림도 이 방법으로 고르게 맞출 수 있다.
- 같은 문구의 짝은 반드시 같은 몫(학습이면 학습)에 넣는다. 짝이 학습과 테스트로 갈리면 문구만 외운 탐지기가 높은 점수를 받는다.

### 5.5 아이디어 3: 공공 사이트에만 있는 자리에 숨긴다

- 「관련 사이트 바로가기」·「패밀리 사이트」 선택 목록(`<select><option>`): 기관명은 그대로, 목적지만 바꾼 링크 클로킹
- 푸터의 기관 배너 줄: 배너 그림은 그대로, 링크만 도박 사이트
- 접근성 숨김 텍스트 자리(`.sr-only`, `.blind`): 화면 낭독기용 문구 대신 광고 문구. DECOY 의 접근성 숨김 170건과 같은 클래스를 써서, 클래스만 보고 판정하는 탐지기를 걸러 낸다
- 메타 클로킹: 공공 사이트 실측 head(title · description · og · JSON-LD)에서 값만 실측 광고 문구로 바꾼다

### 5.6 아이디어 4: 생성 positive 마다 DECOY 짝을 만든다

- 생성 positive 하나마다 같은 숨김 기법에 정상 내용을 넣은 DECOY 하나를 만든다. 기법 신호만 보고 광고로 판정하는 탐지기는 정밀도가 떨어진다.
- 정상 내용은 공공 사이트 실측 공지·정책 문구에서 가져온다.
- 생성 없이 쓸 수 있는 실측 재료도 있다. JS 로딩 전 `opacity:0` 템플릿, 사이트 CSS 때문에 흰 글자가 된 링크, 슬라이더의 비활성 슬라이드다.

### 5.7 생성 목표 개수 (제안, 후순위)

| 무엇 | 개수 | 방법 |
|---|---:|---|
| css_content | 20 | (나) 공공 사이트 실측 CSS 20곳에 한 줄씩 |
| 숨김 + 난독화 조합 | 25 | (가) 에디터 통과 검증을 거친 인라인 숨김 × 실측 조합 문구 |
| 링크 클로킹(공공 자리) | 15 | 5.5 의 선택 목록·푸터·배너 |
| 메타 클로킹 | 10 | (나) 공공 사이트 실측 head 값 치환 |
| Base64 인코딩 | 10 | (다) 탈취 페이지 + (나) 스크립트 안 문자열 |
| 위 각각의 DECOY 짝 | 80 | 5.6 |
