## 실행 환경

- 프로젝트: `C:\Users\user\Desktop\egov-4.3.0`
- 전자정부 공통컴포넌트: 4.3.0
- IntelliJ IDEA, JDK 17, Maven으로 빌드
- 프로젝트 컴파일 언어 수준: Java 8
- MySQL 서버: 사용자 설치 및 접속 출력 기준 26.7.0
- MySQL DB: `com`, 문자 집합 `utf8mb4`, 정렬 `utf8mb4_unicode_ci`
- DB 접속 계정: `com`@`localhost`, 해당 DB 권한 부여
- 원본 DDL 실행 후 테이블 182개 및 뷰 1개 목록 확인
- 원본 DML 실행 후 업무 사용자 수 2개 확인
- Cargo Maven 플러그인 1.10.14, 내장 Tomcat 8.5.100, 포트 8080

DB 비밀번호는 이 기록에 보관하지 않습니다. 화면 로그인용 기본 테스트 계정은 배포 SQL 및 공식 로그인 안내에서 확인했으며 DB 접속 계정과 별개입니다.

## 적용한 설정

`src/main/resources/egovframework/egovProps/globals.properties`에서 MySQL DB와 계정을 지정하고 사용자가 정한 DB 비밀번호를 넣었습니다. 한글 비밀번호는 Java Properties의 기본 읽기 방식에 맞춰 `\uXXXX` 표기로 저장했습니다.

`src/main/resources/egovframework/spring/com/context-crypto.xml`의 `initial`, `crypto`를 각각 `false`로 설정했습니다. `context-datasource.xml`의 MySQL 프로필에서 비밀번호를 다음 속성으로 읽게 변경했습니다.

```xml
<property name="password" value="${Globals.mysql.Password}"/>
```

`pom.xml`의 Cargo 플러그인 안쪽 서버 설정에서 원본의 잘못된 `<property name="cargo.servlet.port" value="8080"/>`를 다음 형식으로 수정했습니다.

```xml
<configuration>
    <properties>
        <cargo.servlet.port>8080</cargo.servlet.port>
    </properties>
</configuration>
```

다운로드 원본 ZIP은 그대로 보존했습니다. 위 설정 변경은 Windows의 실행 프로젝트에 적용한 것입니다.

## 재실행 방법

MySQL 서비스가 실행 중인 상태에서 IntelliJ의 프로젝트를 열고 Ctrl 키를 두 번 눌러 다음 Maven 명령을 실행합니다.

```text
mvn -DskipTests package org.codehaus.cargo:cargo-maven3-plugin:1.10.14:run
```

실행 로그에 `Tomcat 8.x Embedded started on port [8080]`가 나오면 브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:8080/egovframework-all-in-one/
```

서버 프로세스를 중지하면 브라우저에서 접속할 수 없습니다. MySQL에 저장한 게시판과 글은 서버 프로세스를 중지해도 보존됩니다.
