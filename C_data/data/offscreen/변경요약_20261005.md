## visibility_hidden 보충 7개 (10-06)

**출처:** SitePoint 포럼 「Div id='hideMeya' added to the source code of my website」 스레드의 2014-02-18 게시글이다(https://www.sitepoint.com/community/t/div-id-hidemeya-added-to-the-source-code-of-my-website/39004). 피해자가 자기 사이트 소스에서 발견했다며 주입 코드 전문을 붙였다.

**원문 구조:** `div#hideMeya` 안에 광고 링크가 약 40개 있다. 끝의 script 가 `document.getElementById('hideMeya').style.visibility = 'hidden'` 과 `style.display = 'none'` 을 설정해 숨긴다.

| 원문 ID | 시험용 ID | 광고 문구 | 연결 대상 |
|---|---|---|---|
| OF-208 | OF-215 | pay day loan online | cashadvance7online.com |
| OF-209 | OF-216 | viagra coupon pfizer | www10450.b2viagra10.com |
| OF-210 | OF-217 | order viagras online | order2auviagraonline.com |
| OF-211 | OF-218 | levitra coupon | levitra-online2.com |
| OF-212 | OF-219 | cialis cheapest price | www10616.40cialis10.com |
| OF-213 | OF-220 | viagra food | www10075.60viagra10.com |
| OF-214 | OF-221 | online cialis | wwxcialiscom.com |

- **원문 html:** script 의 숨김 선언을 감싸는 요소의 inline style 로 옮겨 재구성했다. 결과는 `<div id="hideMeya" style="visibility:hidden; display:none"><a …>문구</a></div>` 이다. 감싸는 태그의 style 은 원문이 아니며, OF-199~202 와 같은 방식이다. 링크 태그(`href`·`title`·문구)는 게시글 그대로다. 포럼이 따옴표를 둥근 따옴표로 바꿔 보여 주는 것만 곧은 따옴표로 되돌렸다.
- **시험용:** 원문 문구에 Bootstrap `.invisible { visibility: hidden; }` 을 걸었다. 기존 visibility_hidden 시험용(OF-057~060)의 세 변형(글자 요소에 class / 감싸는 요소에 class / 한 겹 더 감쌈)을 돌아가며 썼다.
- **중복 확인:** 광고 문구(대소문자 무시)와 연결 주소가 기존 원문·시험용과 하나도 겹치지 않는다. 처음 고른 `buy cialis` 는 OF-136(text_indent, 다른 링크)과 문구가 같아 `viagra coupon pfizer` 로 바꿨다.
- **쏠림 (그대로 적는다):** visibility_hidden 원문 15개 중 11개가 같은 `hideMeya` 캠페인이다(WordPress Stack Exchange 4 · SitePoint 7). 보충 7개는 모두 한 게시글에서 나왔다. 출처별로는 SitePoint 7 · WordPress Stack Exchange 4 · Ranum 2 · Stack Overflow 1 · Sucuri 1 이다.
- **보충분을 찾은 범위:**
  - 다른 캠페인을 찾으려고 공개 보고서·포럼·블로그를 훑었다. Joomla·Drupal·OrdaSoft·WordPress.org·SitePoint 다른 글, Wordfence·Quttera·Kaspersky·Dynamoo, Unmask Parasites 블로그 아카이브 144편이다.
  - GitHub 이슈 본문 617건도 정규식으로 걸렀다.
  - 숨김 방식이 `display:none`·음수 좌표·숨김 iframe 이거나 예시 코드뿐이었고, 업자가 `visibility:hidden` 으로 광고 링크를 숨긴 원문은 이 게시글들 말고는 나오지 않았다.
