## 2. 고친 것

모든 수정은 `fix_homoglyph.py` 한 파일에 적혀 있고, 원본 폴더를 입력으로 다시 돌리면 같은 결과가 나온다. 고친 행은 `notes` 에 이유를 적었다.

1. **휴대폰 번호 가림 1건 (HG-RT-0041, 권장판 포함).** `010 – XXXX – XXXX` 꼴 번호가 그대로 있었다. 대시 앞뒤에 공백이 있는 꼴이라 원 가림 규칙에서 빠진 것으로 보인다. 가운데 네 자리를 0 으로 바꿨다(사람 2 규칙과 같음).
2. **하위 유형 라벨 수정 5건.**
   - HG-RT-0008, 1086: `ㅋr톡` 인데 partial_token 이었다 → hangul_lookalike.
   - HG-RT-0015, 0016, 0019: `𝐒𝐁𝐌𝐓𝟑`, `𝕙𝕒𝕔𝕜𝕚𝕟𝕘𝕕𝕓` 처럼 토큰 전체가 수학 영숫자인데 partial_token 이었다 → enclosed_alnum.
3. **같은 문장 중복 4쌍에서 뒤 id 삭제.**
   - HG-RT-0014(0010 과 같음), 0016(0015), 0018(0017): 기관 검색결과 페이지 한 쪽에 검색어가 두 자리(검색창 반사와 「검색어」 머리글)로 비친 것이다. 요소는 다르지만 시험 샘플로는 같은 문장 두 번이다.
   - HG-RT-0881(0876): kcoal 게시판 2쪽과 3쪽에 같은 글이 잡혔다. 수집 중 목록이 밀린 것으로 보인다.
4. **글자가 `????` 로 깨진 5건 (HG-RT-0894·0901·0932·1061·1205, 모두 ypcd.or.kr).** 삭제하지 않고 원인을 `notes` 에 적었다.
   - 원인은 사이트 쪽이다. ypcd 의 478건에는 4바이트 문자(수학 영숫자 등)가 하나도 없다. 같은 캠페인이 hannam 에서는 4바이트 문자 그대로 122건 들어 있다. 같은 수집기로 받았으니 ypcd 게시판 DB 가 4바이트 문자를 `?` 로 바꿔 저장한 것이다.
   - 5건 모두 다른 위장 문자(`ι`, `ⓗⓞⓝⓖⓑⓞ`, `➑➋` 등)가 남아 있어 양성 그대로 둔다.

## 3. 키릴·그리스 보충

계획서(`데이터수집_계획_카테고리별_배정.pdf` 2쪽) 쿼터는 키릴·그리스 혼입 25 이고, 권장판 원본은 18 이었다.

**찾은 방법.**
- 사람 2 가 쓴 공공 게시판 11곳의 최신 목록 40쪽씩, 440쪽을 새로 받았다(2026-10-06 22시대, robots.txt 준수, 간격 1.5초, 403/429 없음). 사람 2 의 기준일 10-02 이후 새 글이 올라와 있었다.
- 역할 C 가 10-03~10-05 에 받은 원문(약 2,300쪽)도 같은 검사기로 훑었다.
- 판정 규칙(`scan_cyrillic.py`): 한 토큰 안에서 키릴·그리스 글자가 라틴·숫자와 섞였거나, 키릴·그리스 2글자 이상으로 라틴 단어를 흉내 낸 것. 문장 글자의 절반 이상이 키릴이면 러시아어 스팸이라 뺐다(사람 2 규칙과 같음).

**결과: 진짜 사례 4건.**
- HG-RT-1778~1780: hannam 게시판의 `ㅌㄹнσиgвσ8288` 캠페인. 원본의 같은 캠페인(`token:oo`)이 권장판에 이미 5건 있어 전체판에만 들어갔다.
- HG-RT-1781: `Nandrolone Deсanoate`(키릴 с U+0441 이 라틴 c 자리) 스테로이드·수면제 판매 글이다. **공공 사이트가 아니다**(dkhrainbow.com 상품 문의 게시판). 사람 2 의 공공 도메인 원칙과 다르므로 `source`·`notes` 에 표시했다. 권장판에 들어갔다.

**버린 후보(오탐 58건).**
- kcoal.or.kr 15건: EUC-KR 페이지를 UTF-8 로 읽어 생긴 깨진 글자였다. 페이지가 선언한 문자 집합으로 읽게 고친 뒤 사라졌다.
- cuma.or.kr 7건: `0.47μM` 같은 단위다. 정상 글이라 DECOY 후보로는 쓸 수 있다.
- ypcd.or.kr 3건: 러시아어 스팸이라 뺐다.
- ymhitech 32건: 문자 집합이 어긋나 깨진 한글이었다.

**남은 차이: 19 로 둔다 (2026-10-07 역할 C 결정).** 권장판 키릴·그리스는 **19 / 25** 로 6건 모자란다. 캠페인당 5건 상한을 지키면 실측으로는 더 채울 곳이 없었다.
- 상한을 풀어 채우는 길은 쓰지 않았다. 전체판에서 권장판에 안 든 키릴·그리스 행은 12건이고 그중 11건이 `нσиgвσ` 캠페인이다. 6건을 넣으면 권장판 키릴·그리스 25건 중 10건(40%)이 한 캠페인이 된다.
- 대신 「실제 위장에서 키릴·그리스는 드물다」를 보고서 발견 사항으로 쓴다. 근거: 공공 게시판 19곳 1,777건 가운데 31건이고, 수법으로는 `нσиgвσ`·`ι i nⓔ` 두 캠페인과 단건 몇 개뿐이다. 사람 2 도 같은 관찰을 적었다.

## 4. 그대로 둔 것과 확인할 것

- **계획서 쿼터와 뜻이 다른 두 유형.**
  - 「전각 하이픈·% 기호형」: 요강 예시 `ｍｅｇａ－ＢＥＴ 첫충 30％` 의 U+FF0D·U+FF05 는 0건이다. fullwidth_symbol 479건은 도메인 점 바꾸기이고, 쓰인 점 7종 가운데 전각 문자는 U+FF0E 하나다.
  - 「토큰 일부만 위장」: 계획서는 「평문 문장 속 일부 토큰만 위장」, 사람 2 는 「한 토큰 안 일부 글자만 위장」으로 썼다.
- **기법이 둘 이상 섞인 행 224건.** 라벨은 주된 기법 하나다. 하위 유형별 건수는 그 기준으로 읽어야 한다.
- **k3dprinting.or.kr.** 2026-10-06 에 받은 목록 40쪽 가운데 35쪽을 Windows 백신이 열지 못하게 막았다. 지금 악성 코드를 내보내는 것으로 보인다. 열지 않고 건너뛰었다. 원본 193건의 조각 자체는 백신이 막지 않았다.
- **사람 2 의 팀 확인 요청 넷은 아직 열려 있다.** `ㅋr톡` 을 HOMOGLYPH 로 인정할지, 검색결과 반사 페이지 14건을 정답으로 인정할지, `ⅹ텔레연락ⅹ` 처럼 로마숫자를 구분자로 쓴 경계 사례, 기본 테스트셋을 권장판과 전체판 중 무엇으로 할지.
