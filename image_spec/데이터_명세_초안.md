# 이미지 불법광고 데이터 명세 (초안)

2026-11-03 초안

넘겨주기 일곱 번(H1\~H7)에 오가는 파일의 이름·열·값을 여기서 고정한다. 넷이 확인하고 고친 뒤 확정하며, 확정 뒤에는 열을 바꾸지 않고 새 열만 덧붙인다. 판정 방법(무엇을 불법광고로 볼지의 사례)은 준아의 라벨 가이드라인 v1(11.5)이 맡고, 이 명세는 값의 형식만 정한다.

## 1. 라벨 정의

라벨은 네 갈래이고, 모델의 최종 판정은 `illegal` 대 나머지 셋(정상)의 두 갈래다. 네 갈래로 나눠 적는 이유는 오탐을 갈래별로 세기 위해서다.

| 코드 | 뜻 | 예 | 헷갈리는 경계 |
| --- | --- | --- | --- |
| `illegal` | 불법 상품·서비스를 광고하는 이미지 | 사설 토토·카지노·슬롯 배너, 성매매 광고, 미등록 대부, 처방약 판매 | 합법 사행(복권·스포츠토토)은 `legal_ad` |
| `legal_ad` | 합법 상품·서비스 광고 | 동행복권, 베트맨, 은행 대출, 병원, 쇼핑 할인 배너 | 「가입코드」「먹튀」 같은 불법 업계 은어가 있으면 `illegal` |
| `campaign` | 불법을 경고하는 계도 이미지 | 사감위·경찰청 「불법 도박 근절」 포스터 | 도박 낱말이 들어 있어도 경고면 `campaign` |
| `other` | 광고가 아닌 이미지 | 기관 로고, 행사 사진, 상품 사진, 아이콘 | 행사 안내 배너도 여기 |

`illegal`에는 세부 갈래 `category`를 하나 붙인다. 이름은 1차 갈래 사전을 따른다: `gambling`(도박) · `adult`(성인·유흥) · `forgery`(위조·불법거래) · `loan`(불법 대출) · `drug`(의약품) · `invest`(투자·코인) · `etc`. 나머지 세 갈래는 `category`를 비워 둔다.

판단이 안 서는 이미지는 가장 가까운 라벨을 붙이고 `unsure=1`로 표시한다. `unsure=1`인 이미지는 평가에서 따로 집계한다.

## 2. 데이터 묶음과 목표 건수

묶음은 넷이고 `set` 열에 적는다. 건수는 중복을 묶은 뒤의 수다.

| `set` | 무엇 | 모으는 사람 | 목표 건수 | 쓰는 곳 |
| --- | --- | --- | --- | --- |
| `R_pos` | 실제 불법광고 이미지 | 채현 | 150장, 출처 사이트 20곳 이상 | 학습·검증·평가 |
| `R_hard` | 실제 합법 광고·계도 포스터 | 정연 | 150장 이상 | 학습·검증·평가 |
| `R_gen` | 실제 일반 배너·사진 | 채현 | 450장 이상, 사이트 종류 5개 이상 | 학습·검증·평가 |
| `S` | 합성 이미지 (불법·합법·계도 같은 틀) | 정연 | 최대 2,000장 | 학습만 (계획 B에서는 템플릿 20%가 평가) |

`R_pos`가 11.6 관문에서 100장에 못 미치면 계획 B로 간다. 그때 모은 `R_pos`는 학습에 넣지 않고 현실 점검용으로만 따로 채점한다.

## 3. 공통 규칙

- **이미지 ID:** `image_id` = 묶음 접두어 + 파일 내용 SHA-1의 앞 16자리(소문자). 접두어는 `rpos_` · `rhard_` · `rgen_` · `s_`. 예: `rpos_3f2a9c1e5b7d4e8a`. 내용이 똑같은 파일은 ID가 같아지므로 수집 때 하나만 남긴다
- **비슷한 이미지:** 크기만 다르거나 살짝 잘린 같은 배너는 지우지 않고, 준아가 pHash로 한 묶음(`group_id`)으로 묶는다
- **파일 이름:** `<image_id>.<확장자>`. 원본 형식 그대로 두고 확장자는 소문자(`jpg` `png` `gif` `webp`). SVG는 PNG로 그려 저장한다
- **CSV:** UTF-8(BOM 없음), 쉼표 구분, 첫 줄은 열 이름. 글 안에 쉼표·줄바꿈이 있으면 큰따옴표로 감싼다. 엑셀로 바로 열면 한글이 깨지므로 Google 시트나 pandas로 연다
- **날짜·시각:** ISO 8601, 한국 시간. 예: `2026-11-05T14:30:00+09:00`
- **빈 값과 표시:** 값이 없으면 빈 칸(`NA`·`null` 문자열을 쓰지 않음). 예/아니오는 `1`/`0`
- **저장하지 않는 이미지:** 노출이 있는 성인 이미지, 가로나 세로가 32px 미만인 이미지(아이콘·추적 픽셀). 파일은 버리고 `skipped.csv`에 `page_url, source_url, reason`만 남긴다. `reason`은 `adult` 또는 `too_small`
- **접속 범위:** 피해 페이지에 박힌 이미지는 외부 서버에 있어도 받는다. 불법 사이트로 이동하거나 링크·리디렉트를 따라가지는 않는다. robots.txt와 요청 간격 1초를 지킨다

## 4. 폴더 구조

평가 이미지가 섞인 폴더는 팀 공유 드라이브에 두지 않는다. 공유 드라이브는 넷 모두 열 수 있어서, 폴더별 권한만으로는 분리가 깨지기 쉽다. 그래서 분할 전 원본과 평가 몫은 준아 개인 드라이브에 둔다.

```
팀 공유 드라이브  AIX2_image/
├─ 00_spec/        이 명세, 라벨 가이드라인
├─ 20_kappa/       H1: images/, meta_nolabel.csv  /  H3: label_b.csv
├─ 30_trainval/    H4: images/, split_v1.csv(학습·검증 행만), meta.csv, ocr.csv
├─ 40_synth/       H5: images/, synth_meta.csv
├─ 50_emb/         H6: B1+ 글 임베딩
├─ 60_pred/        H7: pred_<model_id>_s<seed>_val.csv, 추론 노트북
└─ 70_log/         experiments.csv

채현 개인 드라이브  collect/      수집 중 원본. H2에 준아에게 넘기고 지운다
정연 개인 드라이브  collect_hard/ R_hard 원본. H3에 준아에게 넘긴다
준아 개인 드라이브  all/          모든 실제 이미지, 전체 split_v1.csv
                   test/         평가 이미지와 그 ocr.csv (준아만)
                   holdout_synth/ 계획 B의 평가용 합성 이미지
```

| 폴더 | 쓰는 사람 | 읽는 사람 |
| --- | --- | --- |
| `20_kappa/` | 채현(이미지), 정연(라벨) | 정연, 준아 |
| `30_trainval/` | 준아 | 넷 모두 |
| `40_synth/` | 정연 | 넷 모두 |
| `50_emb/` | 채현 | 다영 |
| `60_pred/` | 다영, 채현 | 준아 |
| 준아 개인 `test/` | 준아 | 준아만 |

## 5. meta.csv (H2 채현, H3 정연)

실제 이미지 한 장에 한 줄이다. 채현과 정연이 같은 열로 만들고, 준아가 둘을 합친다. 크롤러 없이 손으로 받은 이미지(주로 `R_hard`)는 화면 정보 열(`render_w`\~`selector`)을 비운다.

| 열 | 형식 | 예 | 뜻 |
| --- | --- | --- | --- |
| `image_id` | 문자 | `rpos_3f2a9c1e5b7d4e8a` | 3절 규칙 |
| `set` | `R_pos` `R_hard` `R_gen` | `R_pos` | 2절 묶음 |
| `file` | 상대 경로 | `images/rpos_3f2a9c1e5b7d4e8a.png` |  |
| `sha1` | 40자리 |  | 파일 내용 SHA-1 전체 |
| `source_url` | URL |  | 이미지 주소(`img src` 또는 CSS `url()`) |
| `page_url` | URL |  | 이미지가 박힌 페이지 |
| `site` | 도메인 | `example.ac.id` | `page_url`의 등록 도메인. 분할 그룹의 단위 |
| `site_type` | 아래 값 중 하나 | `hacked_promo` | 사이트 종류. 종류별 오탐률에 씀 |
| `element` | `img` `css_bg` | `img` | 이미지가 들어간 방식 |
| `w`, `h` | 정수(px) | `728`, `90` | 원본 파일 크기 |
| `render_w`, `render_h` | 정수(CSS px) | `728`, `90` | 화면에 그려진 크기. 숨겨져 있으면 `0` |
| `x`, `y` | 정수(CSS px) | `120`, `1840` | 페이지 왼쪽 위 기준 좌표 |
| `selector` | CSS 선택자 |  | 1차 크롤러와 같은 방식 |
| `link_href` | URL |  | 이미지를 감싼 링크. 없으면 빈 칸. 기록만 하고 따라가지 않음 |
| `alt` | 문자 |  | `img`의 `alt` 글 |
| `lang` | `ko` `en` `id` `zh` `mixed` `none` | `id` | 이미지 속 글의 언어. 라벨 붙일 때 눈으로 정함 |
| `collected_at` | ISO 8601 | `2026-11-05T14:30:00+09:00` |  |
| `label` | 1절 코드 | `illegal` | 채현·정연의 라벨은 초안. 평가셋 정답은 준아가 확정 |
| `category` | 1절 코드 | `gambling` | `illegal`일 때만 |
| `unsure` | `0` `1` | `0` |  |
| `labeler` | 이름 | `채현` |  |

`site_type` 값: `hacked_promo`(해킹·삽입형 홍보 페이지) · `community`(게시판·커뮤니티) · `public`(공공기관) · `shopping` · `news` · `university` · `lottery`(합법 사행 공식) · `finance` · `hospital` · `campaign_org`(사감위·경찰청·지자체) · `other`.

## 6. ocr.csv, meta\_nolabel.csv, label\_b.csv

**ocr.csv (H2 채현).** 실제 이미지 한 장에 한 줄이다. OCR 엔진과 버전은 11.9 전에 고정하고 모든 이미지에 같은 설정을 쓴다. GIF는 첫 프레임만 읽는다.

| 열 | 형식 | 뜻 |
| --- | --- | --- |
| `image_id` | 문자 | meta.csv와 같음 |
| `ocr_engine` | `paddleocr` `easyocr` |  |
| `engine_version` | 문자 | 예: `3.7.0` |
| `text` | 문자 | 글상자를 위에서 아래, 왼쪽에서 오른쪽 순으로 이어 붙인 글(사이는 빈칸 하나). 글이 없으면 빈 칸 |
| `n_boxes` | 정수 | 찾은 글상자 수 |
| `conf_mean` | 0\~1 | 글상자 확신도 평균. 글상자가 없으면 빈 칸 |

글상자별 좌표·글·확신도 원본은 `ocr_boxes.jsonl`(한 줄에 이미지 하나: `image_id`, `boxes`)에 따로 둔다.

**meta\_nolabel.csv (H1 채현 → 정연).** κ용 표본이다. 채현이 모은 `R_pos`와 `R_gen`에서 각각 20%를 시드 고정 무작위로 뽑는다. 열은 meta.csv에서 `label`, `category`, `unsure`, `labeler`를 뺀 것이고, 시드는 같은 폴더의 `seed.txt`에 적는다.

**label\_b.csv (H3 정연 → 준아).** 정연이 채현 라벨을 보지 않고 붙인 라벨이다. 열은 `image_id`, `label`, `category`, `unsure`, `labeler`, `labeled_at`이고 값의 형식은 meta.csv와 같다. 준아가 meta.csv의 채현 라벨과 비교해 Cohen's κ를 낸다.

## 7. split\_v1.csv, synth\_meta.csv

**split\_v1.csv (H4 준아).** 실제 이미지 한 장에 한 줄이다. 전체본은 준아 개인 드라이브에만 두고, `30_trainval/`에는 `train`·`val` 행만 올린다. 동결 뒤에는 고치지 않고, 바꿔야 하면 `split_v2.csv`를 새로 만든다.

| 열 | 형식 | 뜻 |
| --- | --- | --- |
| `image_id` | 문자 |  |
| `set` | `R_pos` `R_hard` `R_gen` |  |
| `split` | `train` `val` `test` | 60 / 20 / 20 |
| `group_id` | 문자 | 같은 그룹은 같은 `split`에만 들어간다 |
| `phash` | 16자리 16진수 | 64비트 pHash |

그룹은 두 조건을 이어 붙여 만든다. pHash 해밍 거리가 문턱 이하인 이미지끼리, 그리고 `site`가 같은 이미지끼리다. 둘 중 하나로라도 이어지면 같은 그룹이다. 문턱과 분할 시드는 `split_v1_readme.txt`에 적고, 파일의 SHA-256을 실험 로그에 남긴다.

**synth\_meta.csv (H5 정연).** 합성 이미지 한 장에 한 줄이다.

| 열 | 형식 | 뜻 |
| --- | --- | --- |
| `image_id` | `s_` + SHA-1 앞 16자리 |  |
| `file` | 상대 경로 |  |
| `template_id` | 문자 | 배치·모양 틀. 계획 B의 평가용 20%는 이 단위로 떼어 낸다 |
| `font`, `background` | 문자 | 글꼴 이름, 배경 종류 |
| `text` | 문자 | 이미지에 넣은 문구 그대로 |
| `label`, `category` | 1절 코드 |  |
| `gen_seed` | 정수 | 이 이미지를 만든 시드 |

계획 B로 가면 정연이 떼어 낸 템플릿의 이미지와 행은 준아에게만 간다. 다영에게 가는 synth\_meta.csv에는 그 행이 없다. 뗀 템플릿 ID 목록과 시드는 `holdout_templates.csv`로 준아에게 함께 넘긴다.

## 8. 임베딩, 예측 파일, 실험 로그

**모델 이름 `model_id`.** `B0` · `B1` · `B1p_tfidf` · `B1p_klue` · `B2` · `M1` · `M2` · `M3`. 절제 실험은 뒤에 붙인다: `M2_nosynth`(합성 뺀 학습), `M1_noaug`(증강 끔).

**글 임베딩 (H6 채현 → 다영).** `50_emb/`에 두 파일과 코드 하나를 둔다.

- `emb_<model_id>.npy`: float32 행렬(이미지 수 × 차원), 학습·검증 몫만
- `emb_<model_id>_index.csv`: `row`, `image_id`. 행렬의 몇 번째 줄이 어느 이미지인지
- `embed.py`: OCR 글을 받아 같은 임베딩을 만드는 코드. 평가 이미지 몫은 준아가 이 코드로 만든다

**예측 파일 (H7).** 모델·시드마다 한 파일, 이미지 한 장에 한 줄이다. 검증 예측 `pred_<model_id>_s<seed>_val.csv`는 모델 담당자가, 평가 예측 `pred_<model_id>_s<seed>_test.csv`는 준아가 추론 노트북으로 만든다.

| 열 | 형식 | 뜻 |
| --- | --- | --- |
| `image_id` | 문자 |  |
| `score` | 0\~1 | 불법광고일 점수. 클수록 불법 |
| `pred` | `0` `1` | 문턱을 넘으면 `1` |
| `threshold` | 0\~1 | 검증셋에서 정한 문턱 |
| `model_id`, `seed` |  |  |
| `config_hash` | 12자리 | 설정 YAML의 SHA-256 앞 12자리 |
| `commit` | 7자리 | git 커밋 ID |
| `llm_called`, `llm_label`, `flipped` |  | M3만: LLM에 물었는지, LLM의 답, 판정이 뒤집혔는지 |

**실험 로그 `70_log/experiments.csv`.** 실험 한 번에 한 줄이다. 열은 `exp_id`, `date`, `owner`, `model_id`, `seed`, `config_hash`, `split_hash`, `train_data`(`real` 또는 `real+synth`), `eval_split`(`val` 또는 `test`), `precision`, `recall`, `f1`, `pr_auc`, `llm_calls`, `cost_usd`, `note`. `eval_split=test` 행은 준아만 쓰고, 그 행 수가 곧 평가셋 채점 횟수다.
