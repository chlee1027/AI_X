# 불법광고 탐지 도구 사용설명서 (초안)

## 첫 장: 결과 파일 위치와 AI API

| 항목 | 값 |
|---|---|
| 적격평가용 결과 파일 | 구동 파일(`run.py`)과 같은 폴더의 `result.json` (`--out 폴더`를 주면 그 폴더) |
| 추가 탐지 결과 파일 | 같은 폴더의 `result_extra.json` |
| 실행 기록 | 같은 폴더의 `run_log.json`(방문 페이지 수·오류·LLM 호출 수와 토큰) |
| 인코딩 | UTF-8, BOM 없음 |
| 사용하는 AI API | **제출판은 쓰지 않는다**(규칙과 학습 모델만으로 동작, 외부 접속 없음). 아래 LLM 설정은 코드에 남긴 선택 기능이며 제출판 exe 에는 들어 있지 않다 |
| 모델 이름 | 환경변수 `LLM_MODEL`, 기본 `claude-opus-5-5` |
| 환경변수 이름 | `ANTHROPIC_API_KEY`(키), `LLM_MODEL`(모델), `LLM_MAX_CALLS`(검사 한 번 최대 호출 수, 기본 2) |
| 키 넣는 곳 | `run.py` 와 같은 폴더의 `.env` 파일. 재빌드 없이 키만 바꾸면 된다 |

`.env` 예:

```
ANTHROPIC_API_KEY=발급받은키
LLM_MODEL=claude-opus-5-5
```

## 실행

```
cd A_crawler
python run.py https://점검할.누리집.go.kr/
```

exe 는 `bash D_ui_docs/build_exe.sh <저장소 밖 작업 폴더>` 로 묶고, `detect_tool.exe https://점검할.누리집.go.kr/` 로 실행한다(옵션 같음).

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--out 폴더` | 구동 파일 폴더 | 결과 파일을 쓸 곳 |
| `--budget 초` | 1500 (25분) | 넘으면 새 페이지를 열지 않고 그때까지의 결과를 씀(요강 상한 30분) |
| `--max-pages N` | 5000 | 방문 페이지 상한 |
| `--workers N` | 6 | 동시에 여는 페이지 수 |

## 무엇을 하나

1. 진입 URL 과 같은 호스트의 링크를 따라 하위 페이지·게시글·쿼리 페이지를 연다. 주소는 요강 규칙대로 합친다(끝 `/`·`#` 이하 무시, 쿼리 항목 순서만 다르면 같은 페이지).
2. 페이지마다 Edge 로 화면을 그려 요소별 계산 스타일(누적 불투명도, 글자색과 실제 배경색의 대비, 글자 크기, 화면 밖 위치, clip 등)을 모은다. iframe 안(여러 겹)도 같이 본다.
3. 기법 신호(숨김·닮은꼴 글자·자모)가 있는 요소마다 내용 판정(문자 n-gram 로지스틱 회귀, CPU)으로 광고인지 본다. (선택 기능: 키가 있으면 점수가 애매한 후보만 끝에서 한 번에 LLM 에 묻는다. 제출판은 쓰지 않는다.)
4. 같은 요소를 하나만 가리키는 선택자를 만들어(`querySelectorAll` 결과가 1개인지 확인) `result.json` 에 쓴다. iframe 안은 `iframe[src="절대주소"] >>> 선택자`.
5. 어떤 예외가 나도 결과 파일은 남긴다. 스크립트가 다른 곳으로 보내는 페이지는 스크립트를 끈 창에서 한 번 더 연다. alert·confirm 창은 자동으로 닫는다.

## 필요한 것

- Windows 11, Microsoft Edge(기본 탑재). exe 는 Edge 를 쓴다(Chromium 은 들어 있지 않다). 파이썬으로 돌릴 때 Edge 가 없으면 Playwright Chromium 을 쓴다. 둘 다 없으면 「Microsoft Edge 가 필요하다」를 `run_log.json` 에 남긴다.
- 결과 파일 형식은 `python A_crawler/check_result.py <결과 폴더>` 로 확인할 수 있다.
- GPU 필요 없음.

## 아직 안 된 것

- exe 는 묶었으나(290MB, onedir) 깨끗한 PC·Defender 에서 실행 확인을 안 했다.
- Edge 가 없는 PC 대비는 정하지 않았다.
- 결과 화면(UI)은 없다(D 몫).
