# D. UI · 패키징 · 문서 · 제출

담당자 화면, Windows 11 실행 파일, 제출 서류를 맡는다. 제출 책임자다.

| 산출물 | 내용 |
|---|---|
| `ui/` | 탐지 결과 대시보드 · 건별 근거 · 정탐/오탐 표시 · 내보내기 |
| `build/` | PyInstaller(onedir) 빌드 설정 · 클린 VM 검증 기록 |
| `docs/` | 사용설명서 · 실행/빌드 매뉴얼 · `THIRD_PARTY.md` · 제출 점검표 |
| 서식 1~4 | 참가신청서 · 서약서 · 개인정보 동의서(팀 전원) · 기획서(5~10매) |
